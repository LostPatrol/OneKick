# One Kick

[English](README.md)

One Kick 是一款围绕“踢”展开的 Minecraft NeoForge 模组。

按 **R** 朝准星方向踢击；可以在游戏的“按键绑定”中修改按键。玩家移速和靴子品质会提高踢击力度，目标最大生命值越高则越难踢远。被踢飞的生物高速撞墙时会受到动能伤害。

靴子附魔可以扩展踢击能力：

- **反作用**与**空气动力学**可以把踢击变成位移手段；
- **蓄力**提供长按蓄力条，以食物能量换取更强踢击；威力随蓄力值按二次曲线增长，**超量充能**会成倍提高蓄力上限；
- **崩解**与**不稳定碰撞**会在被踢生物碰撞时破坏地形或引发爆炸；
- **动能过载**大幅提高速度与伤害；
- **角动量守恒**会让被踢飞的生物旋转；
- 原版**精准采集**现在可附魔到靴子上，并保留踢击破坏方块的对应掉落；服务端启用动能过载掉落保护时除外。

模组另有独立进度页，包含 13 项进度，从第一次踢击逐步延伸至最高蓄力、马赫环击飞、大范围破坏与完全体附魔的 **OneKick!**。

## 运行要求

- Minecraft 1.21.1
- NeoForge 21.1.235 或 21.1 系列中的更高版本
- Java 21

## 当前状态

开发构建已具备核心玩法，目前没有发布可供下载的正式版本。

蓄力值会在附魔对应的上限停止增长，**超量充能 I–II** 会将该上限提高至 2–3 倍。蓄力 V 与超量充能 II 的满蓄力一击在释放时单独消耗约 35 点食物能量；蓄力过程会另行消耗食物能量，即使满饱和度与满饥饿值也可能不足以自然蓄满。被踢生物会沿服务端控制的弹道曲线飞行：踢得越重，曲线越平缓、飞行距离越远。踢击动作本身不会造成伤害；只有生物之后发生碰撞时才会受到动能伤害，崩解可在强制穿行期间追加伤害。不稳定碰撞会把本次动能撞击伤害无衰减地施加给爆炸范围内的实体，但不会击退它们。若运动方向偏离初始方向过多，拖尾与后续撞击效果都会停止。崩解每次撞击最多生成 64 个飞散方块实体；当前调试版本仍暂时不限制踢击和地形破坏的上限，测试极端数值前请备份存档。

## 服务端掉落保护

动能过载方块掉落保护默认启用。启用后，只要靴子带有**动能过载**，其踢击破坏地形时便不会生成方块本体掉落或飞散碎块落地掉落，不设撞击速度门槛；容器内部物品仍会正常掉落。

权限等级 2 的管理员可在游戏内查询或修改，无需重启：

```text
/onekick kinetic_overload_drop_protection
/onekick kinetic_overload_drop_protection true|false
```

设置会持久化至世界的 `serverconfig/onekick-server.toml`，配置项为 `performance.suppressKineticOverloadBlockDrops`。
