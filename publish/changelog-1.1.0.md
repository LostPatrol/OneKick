# 1.1.0-CHANGELOG

# NEW

+ Added Singularity, a treasure boot enchantment that lets fully charged kicks with Charge V, Overcharge II, and Disintegration erase any block, including bedrock.
+ Added Afterburner, a rare boot enchantment that burns kicked creatures, leaves flame and smoke trails, ignites nearby ground during low flight, and adds fire to Unstable Collision explosions.
+ Added the Override challenge for erasing a bedrock block.
+ Added the Trailblazer advancement for igniting over 100 blocks in a single kick.
