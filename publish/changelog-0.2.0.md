# 0.2.0-CHANGELOG

# FIX

+ Kick and charge animations now support CPM player models whose animated leg uses CPM's standard `RIGHT_LEG` root, in both first- and third-person views.
+ On Minecraft 1.21.1, fixed a compatibility issue with Player Animation Library and The Awakening that could make the player's head or body appear inside the first-person camera during abilities.
